CWM SORTING ประเมินผลงานคัดรายกะ (ทดลอง)

กะ Night ของวันที่ X = 20:00 วันที่ X ถึง 08:00 วันถัดไป

วันที่ กะ ชม.ทำงาน งานที่มีให้คัด เป้าของกะ คัดได้ ผลงานเทียบเป้า ชิ้น/ชม.ทำงาน เป้าแบบชิ้น
เลือกช่วงวันที่แล้วกด "แสดงรายงาน"

เป้าการคัดแยกตามเคส: รุ่น × อาการ NG (ชิ้น/ชั่วโมง)

รุ่น *DEFAULT* = ใช้กับทุกรุ่น · อาการว่าง = ใช้กับทุกอาการ — ระบบหาเป้าตามลำดับ: รุ่น+อาการ → ทุกรุ่น+อาการ → รุ่น+ทุกอาการ → ทุกรุ่น+ทุกอาการ (ถ้าไม่เจอเลย เคสนั้นจะไม่ถูกนำมาคิดเป้า)

รุ่น (Model)อาการ NGเป้า (ชิ้น/ชม.)

เฉพาะ Admin เท่านั้นที่แก้ไขเป้าได้

วิธีคิดเป้าของกะ

คิดเป้าของกะเป็น "ชั่วโมงตามเป้า" ก่อน แล้วค่อยแปลงเป็นชิ้น เพื่อให้สินค้าที่คัดเร็วกับคัดช้าเทียบกันได้

  1. ชั่วโมงทำงาน = เวลากะที่นับ − เวลาพักตามตาราง
    • ไม่มี OT: นับถึงเวลาเลิกงานปกติ (Day 17:00 / Night 05:00)
    • มีการบันทึกยอดตั้งแต่เวลาเริ่ม OT (17:30 / 05:30) ขึ้นไป: นับถึงสิ้นกะ (20:00 / 08:00)
  2. งานที่มีให้คัด = ยอดที่ค้างอยู่ตอนเริ่มกะ + งานที่ลงทะเบียนเข้ามาระหว่างกะ แปลงเป็นชั่วโมงด้วยเป้าของแต่ละเคส (รุ่น × อาการ NG: ชิ้น ÷ เป้าชิ้น/ชม.)
  3. เป้าของกะ = ค่าที่น้อยกว่าระหว่างข้อ 1 ("ตามกำลังคน") กับข้อ 2 ("ตามงานที่มีให้คัด")
  4. ผลงานเทียบเป้า (%) = ชั่วโมงที่คัดได้ ÷ เป้าของกะ โดยชั่วโมงที่คัดได้ = ชิ้นที่คัดแต่ละเคส ÷ เป้าของเคสนั้น
  5. ชิ้น/ชม.ทำงาน = ชิ้นที่คัดได้ทั้งหมด ÷ ชั่วโมงทำงาน (แสดงไว้ดูเฉยๆ ไม่ได้ใช้ตัดสินผลงาน)
  6. เป้าแบบชิ้น = เป้าของกะ (ชม.) × ชิ้นที่คัดได้ ÷ ชั่วโมงที่คัดได้ (ตามสัดส่วนสินค้าที่คัดจริง)

หมายเหตุ

  • ยอดที่คัดได้มาจากชีต Sort_Log ซึ่งบันทึกทุกครั้งที่ผู้คัดกด "ส่งให้ QC ตรวจ" — นับเข้ากะตามเวลาที่ส่งยอด และนับยอดให้ชื่อผู้คัดที่ส่งยอด
  • งานที่ QC ตีกลับแล้วคัดซ้ำ นับเฉพาะยอดที่คัดเพิ่มในรอบใหม่
  • งานค้างตอนเริ่มกะ = งานที่ลงทะเบียนก่อนเริ่มกะ และยังไม่มีการส่งยอดคัดก่อนเริ่มกะ
  • คิดเป็นภาพรวมทั้งกะ (ไม่แยกรายคน) — ยอดรายคนแสดงไว้ดูประกอบ
  • กะที่ไม่มีการบันทึกยอดเลย จะไม่ถูกนำมารวมในสรุปรายวัน
